# Contributing

Thanks for your interest in OpenForgeCAD.

The project is currently in planning and research, and active implementation is on hold. Early contributions should focus on research, architecture reviews, licensing considerations, and small, evidence-backed proposals.

## Before proposing implementation work

1. Read the README and relevant documents under `docs/`.
2. Explain the problem and the user benefit.
3. Identify alternatives and tradeoffs.
4. Include sources or reproducible test results for technical claims.
5. Avoid adding dependencies before a concrete need has been demonstrated.

## Engineering principles

- Prefer small, reviewable changes.
- Include tests for behavior changes.
- Document platform-specific assumptions.
- Keep AI optional.
- Do not claim GPU acceleration without benchmarks.
- Treat plugin security and document integrity as design requirements.
- Do not copy proprietary implementation details or assets from other CAD products.

A detailed code style and pull-request process will be added once the project has a working codebase.
